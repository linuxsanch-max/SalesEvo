# SalesEvo 🚀

**El agente IA que vende, negocia y cierra tratos 24/7**  
Combinando las técnicas de Grant Cardone, Jordan Belfort, Chris Voss, Zig Ziglar Y Brian Tracy.  
Se autoeduca con libros y vídeos de los mejores closers.

**Objetivo**: Resolver el dolor de millones de freelancers, solopreneurs y mipymes que pierden ventas por no saber negociar.

Construido 100% no-code con **Dify.ai** + RAG.

Próximos pasos:
- MVP en Dify con conocimiento base
- Integración WhatsApp + Stripe
- Postulación a Moonshot 2026

¡Bienvenido al futuro de las ventas!
